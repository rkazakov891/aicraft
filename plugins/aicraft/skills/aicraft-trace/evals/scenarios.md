# Behavioral evaluation setup

Run in an isolated consumer fixture under `.local/`, following `docs/evals.md` in the development repository. Build the fixture described by each prompt before the run; include a valid local AiCraft configuration, product brief, selected bundle, and the stated prior evidence. Do not give expected outputs to the evaluated worker. Capture actual artifacts and transcript before grading. External publication and deployment are disabled. These cases are not marked executed by the deterministic helper test suite.
